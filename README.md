# Français Test 🇫🇷

Современный адаптивный сайт для изучения французского языка через тесты с системой
профилей, статистики и игровой мотивацией (XP, уровни, рекорды, достижения, рейтинг).

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173

## Реализованные разделы (по ТЗ)

- **Accueil** — категории, уровни A1–C1, популярные/новые тесты, поиск, статистика, уровень/XP/ранг.
- **Tests** — список с поиском (только по названию), фильтрация по категории и уровню.
- **Страница теста** — info, «Commencer le test», случайный порядок вопросов и вариантов.
- **Защита от списывания** — отслеживание ухода со страницы/переключения вкладки, включается на уровне теста (режим «strict»).
- **Результат** — счёт, %, XP, баллы, новые достижения, кнопки.
- **Разбор ответов** — вопрос/ваш ответ/правильный ответ/объяснение; ошибки попадают в «Mes erreurs».
- **Jeu** (единый раздел): Niveau/XP, Classement (всё время/неделя/месяц), Records, Classement par test, Succès.
- **Profil** — полная статистика, достижения, история, уровень, ранг.
- **Публичный профиль** — без приватных данных (email/пароль скрыты).
- **Mes favoris / Mes erreurs**.
- **Авторизация** — регистрация, вход, выход, восстановление пароля, смена пароля/имени/аватара.
- **Paramètres** — тема (тёмная/светлая), язык, имя, аватар, пароль, уведомления.
- **Admin-панель** — Dashboard, управление пользователями (блокировка), категориями, тестами, вопросами, статистика.
- **Защита результатов (§14)** — корректность/XP/баллы/уровень/достижения/ранг вычисляются только «серверной» логикой (см. ниже).
- **Учебная программа** — 74 тематических теста по теме (грамматика, спряжение, выражение) + 4 теста на перевод (A1/A2/B1/B2) — всего ~1000 вопросов (уровни A1–B2).

## Технологии

- **Frontend:** React 18 + React Router + Vite.
- **Backend/БД:** по умолчанию — локальный провайдер данных (demo) с той же логикой
  защиты, что и на сервере. Готовое подключение к **Supabase** приложено.

## Архитектура данных

Вся «серверная» логика (подсчёт результата, XP, уровней, достижений, рейтинга)
находится в `src/lib/engine.js`. Локальный провайдер `src/lib/db.js` использует
хранилище браузера как имитацию БД, но применяет те же проверки на стороне данных —
клиент не может «подсунуть» свой результат.

## Подключение живого Supabase

1. Создай проект на https://supabase.com.
2. Выполни `supabase/schema.sql` (таблицы + RLS).
3. Разверни Edge Function `supabase/functions/submit/index.ts` — она считает
   результат **на сервере** (возвращает только итог, клиент не пишет xp/pct/points сам).
4. В `.env` укажи `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`, затем включи
   адаптер в `src/lib/supabase.js` и слей его с `src/lib/db.js`.

Благодаря RLS пользователь пишет только свои записи, а изменять XP/уровень/баллы
могут лишь серверные функции (service_role).

## Google-вход (OAuth)

Кнопка «Continuer avec Google» (страница `Connexion / Inscription`) использует
Supabase Auth как сторону входа. Пока в `.env` нет ключей, кнопка показывает
сообщение о неконфигурированном входе и сайт работает в локальном демо-режиме.

Чтобы включить **реальный** Google-вход:

1. **Supabase:** Dashboard → Authentication → Providers → включи **Google**.
   Скопируй показанный Redirect URL (вида `https://<project>.supabase.co/auth/v1/callback`).
2. **Google Cloud Console** (https://console.cloud.google.com → APIs & Services → Credentials):
   - создай/возьми OAuth 2.0 Client ID (тип Web application);
   - в **Authorized redirect URIs** добавь Redirect URL из п.1;
   - скопируй Client ID и Client secret.
3. **Вернись в Supabase**, вставь Client ID и Client secret в провайдера Google, сохрани.
4. В корне проекта создай файл `.env` (см. `.env.example`):
   ```
   VITE_SUPABASE_URL=https://<project>.supabase.co
   VITE_SUPABASE_ANON_KEY=<anon key>
   ```
5. Перезапусти `npm run dev`. Кнопка Google станет активной.

Как это работает в коде: `src/lib/supabase.js` открывает popup Google через
`auth.signInWithOAuth`; `AppContext` слушает `onAuthStateChange` и через
`auth.googleUser()` (`db.js`) создаёт/подхватывает локальную запись пользователя
по email Google (с 90-дневным доступом, XP и статистикой), открывая сессию сайта.

```
  components/ Layout, UI
  pages/      все страницы

supabase/     schema.sql + Edge Function (проверка на сервере)
```
